# NTPU Student Self-Governance Open Data Repository

[English](README.md) | [繁體中文](README-zh.md)

This repository is the open data and automated workflow hub of the National Taipei University Student Self-Government Association.

The project stores open data — including rosters of student representatives, self-governance statues, and parliamentary records of the Sanxia Campus Student Congress (such as motions and committee report proposals) — as structured data (mostly JSON), serving as an independent data source. The project is fully decoupled from frontend web applications (such as [Legislative Hub](https://github.com/ntpusu/legislative-hub) and the Sanxia Campus Student Parliament's [second-generation motion inquiry system](https://github.com/ntpusu/open-parliament)), and is periodically updated through automated scripts, ensuring that each of those applications can always retrieve the latest and stable open data.

The automatic updates of Sanxia Campus Student Parliament data only cover records up to November 16, 2026.

## Repository Structure

This repository uses a flat structure, divided into three main parts: automated workflows, execution scripts, and data storage:

- **`.github/workflows/`**
  Contains GitHub Actions scheduled workflows responsible for periodically triggering data update tasks.
- **`scripts/`**
  Houses the Node.js scripts that actually perform data fetching and transformation.
- **`data/`**
  Stores the latest structured parliamentary data generated by the scripts, for example:
  - `bill_latestTerm.json`: Bill data for the latest term.
  - `bill_pastTerms.json`: Archived bill data from previous terms.
  - `committeeReports.json`: Policy recommendation reports from each committee and Student Union responses.
  - `bylaw-list.json`: List of self-governance regulations.
  - `bylaws/**.md`: Plain-text files of self-governance regulations.
  - `representatives.json`: Rosters of student representatives for each meeting, seating distribution, and member assignments.

## Automated Workflow Mechanism

This project leverages GitHub Actions for automated data maintenance. Scheduled tasks periodically run the programs in the `scripts/` directory to automatically fetch and process the latest parliamentary content from Google Workplaces.

When a script detects substantive changes through comparison, GitHub Actions automatically writes the changes to the JSON files in the `data/` directory and generates a commit pushed to this repository, keeping the database consistently up to date and reducing the cost of manual maintenance.

## System Integration and Data Access

This project itself contains no frontend rendering logic. The main project (such as the Congress website frontend) or other applications should fetch the JSON files in this repository's `data/` directory via the **jsDelivr CDN**. jsDelivr automatically mirrors this repository's `main` branch and provides stable, globally distributed edge acceleration.

**Recommended CDN base URL:**

```
https://cdn.jsdelivr.net/gh/ntpusu/legislative-data@main/data/{filename}
```

**Implementation notes (for developers' attention):**
Since this repository is updated daily, after each data update GitHub Actions automatically calls jsDelivr to purge the cache, ensuring data timeliness. GitHub's native Raw URLs are therefore not recommended for production environments, to avoid excessive bandwidth consumption and possible request rate limits. If the main project still requires further caching, it may implement additional application-layer caching on the server side (such as in a Nuxt Server API).

## Maintainers

Regarding the data in this repository, the rosters of student representatives are maintained by the Sanxia Campus Student Union, the regulations are maintained by their respective competent units, and the parliamentary data of the Sanxia Campus Student Parliament is managed and maintained by its Secretariat.

Adjustments to automated scripts or changes to the system architecture are handled by the Website Team of the NTPUSU.
